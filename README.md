## Why this exists

Most courses teach features; you finish able to *define* things but freeze on a real task. This repo teaches the subject as a **system for solving a business problem**, built around one continuous project, so that afterwards you can take a real requirement and actually design, build, and explain the solution.

## What's inside

| Doc | What it is |
|---|---|
| [Visual Mind-Map Mastery](docs/01-visual-mindmap-mastery.md) | The flagship **visual** course — mind maps, analogies, memory hooks, and active-recall drills. Redraw it from memory. |
| [Project-Ready Course](docs/02-project-ready-course.md) | The structured **6-hour project-ready course** — one running project, hands-on exercises, checkpoints, cheat sheets, interview bank. |

## How to use

1. Read the **visual mind-map** doc first — one concept, one picture, one memory hook at a time.
2. Work the **project-ready course** — attempt each exercise *before* reading the solution; take the checkpoints honestly.
3. Grade yourself strictly against the readiness scorecard at the end.
4. Come back and drill the interview bank out loud.
